    Section 1.3 Identities and Other Hyperbolic Functions

    A similar identity to the trigonometric identity \(\cos^2 x + \sin^2 x = 1\) holds for the hyperbolic functions:
    \begin{equation} \cosh^2 x - \sinh^2 x = 1.\tag{1.3.1} \end{equation}
    🔗
    As you already know, any point \(P(x,y)\) on the circumference of the unit circle \((x^2 + y^2 = 1)\) can be described in terms of sine and cosine of an angle \(t \in [0, 2\pi)\text{,}\) i.e. \(x = \cos t\) and \(y = \sin t\text{,}\) which results in the trigonometric identity \(\cos^2 t + \sin^2 t = 1\text{.}\) See Figure 1.3.1.
    🔗
    Similarly, any point \(P(x,y)\) on the right branch of the hyperbola \(x^2 - y^2 = 1\) can be represented as \(x = \cosh t\) and \(y = \sinh t\text{,}\) where \(t \in \R\text{.}\) This follows directly from identity (1.3.1), i.e. \(\cosh^2 t - \sinh^2 t = 1\text{.}\) See Figure 1.3.2.
    🔗

    Checkpoint 1.3.3. Parametrizing the Left Branch.

    Both branches of \(x^2 - y^2 = 1\) are drawn in Figure 1.3.2, but the parametrization \(P(\cosh t, \sinh t)\) traces only the right one, since \(\cosh t \geq 1\) for every \(t \in \R\text{.}\) How would you parametrize the left branch, where \(x \leq -1\text{?}\)
    🔗
    Hint.
    The identity \(\cosh^2 t - \sinh^2 t = 1\) is unaffected if you change the sign of the first coordinate.
    🔗
    🔗
    Answer.
    \((x,y) = (-\cosh t, \sinh t)\) for \(t \in \R\text{.}\)
    🔗
    🔗
    Solution.
    Every point of the hyperbola satisfies \(x^2 = 1 + y^2 \geq 1\text{,}\) so \(\left|x\right| \geq 1\text{;}\) the left branch is the part where \(x \leq -1\text{.}\)
    🔗
    Start with a point \((x,y)\) on that branch. Since \(\sinh \colon \R \to \R\) is one-to-one and onto, there is exactly one \(t \in \R\) with \(y = \sinh t\text{.}\) For that \(t\text{,}\)
    \begin{equation*} x^2 = 1 + y^2 = 1 + \sinh^2 t = \cosh^2 t, \end{equation*}
    so \(x = \pm \cosh t\text{,}\) and \(x \leq -1 \lt 0\) forces \(x = -\cosh t\text{.}\) Hence every point of the left branch has the form \((-\cosh t, \sinh t)\text{.}\)
    🔗
    Conversely, each such point does lie on the left branch:
    \begin{equation*} (-\cosh t)^2 - \sinh^2 t = \cosh^2 t - \sinh^2 t = 1, \end{equation*}
    and \(-\cosh t \leq -1\text{.}\) Therefore
    \begin{equation*} x = -\cosh t, \qquad y = \sinh t, \qquad t \in \R \end{equation*}
    parametrizes the left branch exactly once, and geometrically it is the mirror image across the \(y\)-axis of the parametrization of the right branch.
    🔗
    🔗
    🔗

    Checkpoint 1.3.4. True or False.

      The parametrization \(x = -\cosh t\text{,}\) \(y = -\sinh t\text{,}\) \(t \in \R\text{,}\) also traces the left branch of \(x^2 - y^2 = 1\text{.}\)
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • Every such point lies on the hyperbola, since
      \begin{equation*} (-\cosh t)^2 - (-\sinh t)^2 = \cosh^2 t - \sinh^2 t = 1, \end{equation*}
      and on its left branch, since \(-\cosh t \leq -1\text{.}\) As \(t\) runs over \(\R\text{,}\) so does \(y = -\sinh t\text{,}\) so the whole branch is covered. It sweeps out the same branch as \((-\cosh t, \sinh t)\text{,}\) only downward instead of upward as \(t\) increases.

    • False.

    • Every such point lies on the hyperbola, since
      \begin{equation*} (-\cosh t)^2 - (-\sinh t)^2 = \cosh^2 t - \sinh^2 t = 1, \end{equation*}
      and on its left branch, since \(-\cosh t \leq -1\text{.}\) As \(t\) runs over \(\R\text{,}\) so does \(y = -\sinh t\text{,}\) so the whole branch is covered. It sweeps out the same branch as \((-\cosh t, \sinh t)\text{,}\) only downward instead of upward as \(t\) increases.
    🔗
    As you might have guessed, the rest of the hyperbolic functions are defined as follows.
    \begin{align*} \tanh x \amp = \frac{\sinh x}{\cosh x} \amp \operatorname{sech} x \amp = \frac{1}{\cosh x}\\ \coth x \amp = \frac{\cosh x}{\sinh x} \amp \operatorname{csch} x \amp = \frac{1}{\sinh x} \end{align*}
