    Worksheet 22.2 Exercises for Infinite Series
    

    These problems work with sequences and finite sums, and ask whether a series converges and, when it does, what it sums to. If you would like to review this topic before attempting them, see Infinite Series.
    🔗

    1.

    If \(a, b, a+b\) and \(ab\) are positive numbers that form 4 consecutive terms in a geometric sequence, find \(a\text{.}\)
    🔗
    Solution.
    Since consecutive ratios in a geometric sequence are equal,
    \begin{equation*} \frac{a}{b} = \frac{b}{a+b} = \frac{a+b}{ab}. \end{equation*}
    🔗
    From the first equality,
    \begin{gather*} \frac{a}{b} = \frac{b}{a+b} \;\Rightarrow\; a^2 + ab = b^2 \;\Rightarrow\; b^2 - ab - a^2 = 0\\ \;\overset{\div\, a^2}{\Rightarrow}\; \left(\frac{b}{a}\right)^{2} - \left(\frac{b}{a}\right) - 1 = 0\\ \frac{b}{a} = \frac{1 \pm \sqrt{1+4}}{2} \;\overset{\text{since } b/a \gt 0}{\Rightarrow}\; \frac{b}{a} = \frac{1 + \sqrt5}{2}. \quad (\ast) \end{gather*}
    🔗
    From the equality of the first and third fractions,
    \begin{align*} \frac{a}{b} = \frac{a+b}{ab} \;\Rightarrow\; a^2 = a + b \;\overset{\div\, a}{\Rightarrow}\; a \amp = 1 + \frac{b}{a}\\ \amp \;\overset{(\ast)}{=}\; 1 + \frac{1+\sqrt5}{2} = \frac{3 + \sqrt5}{2}. \end{align*}
    🔗
    🔗
    🔗

    2.

    The terms of a geometric series \(a + ar + ar^2 + \cdots + ar^{n-1} + \cdots\) satisfy
    \begin{equation*} a_5 + a_7 = 1500 \quad\text{and}\quad a_{11} + a_{13} = 187500, \end{equation*}
    where \(a_n = ar^{n-1}\) denotes the \(n\)th term. Find \(a_1 + a_2 + a_3\text{.}\)
    🔗
    Solution.
    Using \(a_n = ar^{n-1}\text{,}\)
    \begin{align*} a_5 + a_7 \amp = ar^4 + ar^6 = ar^4(1 + r^2) = 1500,\\ a_{11} + a_{13} \amp = ar^{10} + ar^{12} = ar^{10}(1 + r^2) = 187500. \end{align*}
    Dividing the two equations,
    \begin{equation*} \frac{a_{11} + a_{13}}{a_5 + a_7} = \frac{ar^{10}(1+r^2)}{ar^{4}(1+r^2)} = \frac{187500}{1500} \;\Rightarrow\; r^6 = 125 = 5^3 \;\Rightarrow\; r^2 = 5. \end{equation*}
    🔗
    Substituting back,
    \begin{equation*} ar^4(1 + r^2) = 1500 \;\Rightarrow\; a(25)(1+5) = 1500 \;\Rightarrow\; a = \frac{1500}{150} = 10. \end{equation*}
    Since \(r^2 = 5\text{,}\) we have \(r = \pm\sqrt5\text{,}\) and therefore
    \begin{align*} a_1 + a_2 + a_3 \amp = a + ar + ar^2 = a(1 + r + r^2)\\ \amp = 10\left(1 \pm \sqrt5 + 5\right) = 10\left(6 \pm \sqrt5\right). \end{align*}
    🔗
    🔗
    🔗

    3.

    Consider the sequence defined by \(a_1 = 1\) and \(a_{n+1} = a_n + 3n^2 + 3n + 1\text{.}\) Find a formula for \(a_n\) and use it to compute \(a_{200}\text{.}\)
    🔗
    Solution.
    We compute the first few terms:
    \begin{align*} n = 1: \quad a_2 \amp = a_1 + (3 + 3 + 1) = 1 + 7 = 8 \;\Rightarrow\; a_2 = 2^3\\ n = 2: \quad a_3 \amp = a_2 + (12 + 6 + 1) = 8 + 19 = 27 \;\Rightarrow\; a_3 = 3^3 \end{align*}
    We notice that \(a_1 = 1^3\text{,}\) \(a_2 = 2^3\text{,}\) and \(a_3 = 3^3\text{,}\) hence it seems that \(a_n = n^3\text{.}\)
    🔗
    Let us verify by computing \(a_{n+1} - a_n\) using \(a_n = n^3\text{:}\)
    \begin{align*} a_{n+1} - a_n \amp = (n+1)^3 - n^3\\ \amp = n^3 + 3n^2 + 3n + 1 - n^3 = 3n^2 + 3n + 1, \end{align*}
    which confirms that when \(a_n = n^3\text{,}\) then \(a_{n+1} = a_n + 3n^2 + 3n + 1\text{.}\) Hence,
    \begin{equation*} a_{200} = (200)^3 = 8 \times 10^{6}. \end{equation*}
    🔗
    🔗
    🔗

    4.

    What is the sum of all multiples of 7 or 11 less than 1000?
    🔗
    Solution.
    Note that we need to subtract the multiples of \(77\text{,}\) since they have been added twice:
    \begin{align*} \amp \underbrace{(7 + 14 + 21 + \cdots + 77 + \cdots + 994)}_{\text{multiples of } 7}\\ \amp \quad + \underbrace{(11 + 22 + \cdots + 77 + \cdots + 990)}_{\text{multiples of } 11}\\ \amp \quad - \underbrace{(77 + 154 + \cdots + 924)}_{\text{multiples of } 77}\\ \amp = 7(1 + 2 + 3 + \cdots + 142) + 11(1 + 2 + 3 + \cdots + 90)\\ \amp \quad - 77(1 + 2 + \cdots + 12) \end{align*}
    🔗
    Using \(\displaystyle\sum_{i=1}^{n} i = \frac{n(n+1)}{2}\text{:}\)
    \begin{align*} \amp = 7\,\frac{(142)(143)}{2} + 11\,\frac{(90)(91)}{2} - 77\,\frac{(12)(13)}{2}\\ \amp = 7(71)(143) + 11(45)(91) - 77(6)(13)\\ \amp = (7)(71)(13)(11) + (11)(13)(7)(45) - (7)(11)(6)(13)\\ \amp = (7)(11)(13)(71 + 45 - 6) = (7)(11)(13)(110) = 110110, \end{align*}
    where we used \(143 = (13)(11)\) and \(91 = (13)(7)\text{.}\)

    5.

    What can we conclude by applying the \(n\)th term test in the following series?
    1. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{3n}{\sqrt{6n^2 + 4n + 5}}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{(5n+3)^{2n}}{(7n^2+2)^{n}}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{2\ln(n)}{3n}\)
      🔗
      🔗
    🔗
    Solution.
    1. \begin{align*} \lim_{n\to\infty} \frac{3n}{\sqrt{6n^2+4n+5}} \amp = \lim_{n\to\infty} \frac{3n}{\sqrt6\, n} = \sqrt{\frac32} \ne 0\\ \amp \;\Rightarrow\; \text{the series diverges.} \end{align*}
      🔗
      🔗
    2. \begin{align*} \lim_{n\to\infty} \frac{(5n+3)^{2n}}{(7n^2+2)^{n}} \amp = \lim_{n\to\infty} \left(\frac{(5n+3)^2}{7n^2+2}\right)^{n} = \lim_{n\to\infty} \left(\frac{25n^2 + 30n + 9}{7n^2+2}\right)^{n}\\ \amp = \lim_{n\to\infty} \left(\frac{25}{7}\right)^{n} = \infty \;\Rightarrow\; \text{the series diverges.} \end{align*}
      🔗
      🔗
    3. \begin{align*} \lim_{n\to\infty} \frac{2\ln(n)}{3n} \amp \;\overset{\text{H}}{=}\; \frac23 \lim_{n\to\infty} \frac{1/n}{1} = 0\\ \amp \;\Rightarrow\; \text{the } n\text{th Term Test is inconclusive.} \end{align*}
      🔗
      🔗
    🔗

    6.

    Evaluate the following sums or show that they diverge.
    1. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{1}{n(n+1)(n+2)}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} e^{-2n}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle\sum_{n=0}^{10} e^{-2n}\)
      🔗
      🔗
    4. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} e^{2n}\)
      🔗
      🔗
    5. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{6}{(2n-1)(2n+1)}\)
      🔗
      🔗
    6. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{2n+1}{n^2(n+1)^2}\)
      🔗
      🔗
    7. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \ln\!\left(\frac{n}{2n+1}\right)\)
      🔗
      🔗
    8. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \left(1 + \frac4n\right)^{n}\)
      🔗
      🔗
    9. \(\displaystyle \displaystyle\sum_{n=2}^{\infty} \frac{2}{3^n}\)
      🔗
      🔗
    10. \(\displaystyle \displaystyle\sum_{n=3}^{\infty} \frac{2^n}{3^n}\)
      🔗
      🔗
    🔗
    Solution.
    1. We use partial fractions:
      \begin{align*} \frac{1}{n(n+1)(n+2)} \amp = \frac{A}{n} + \frac{B}{n+1} + \frac{C}{n+2}\\ \amp = \frac{A(n+1)(n+2) + Bn(n+2) + Cn(n+1)}{n(n+1)(n+2)}. \end{align*}
      Setting \(n = 0\) gives \(2A = 1\text{,}\) so \(A = \frac12\text{;}\) setting \(n = -1\) gives \(-B = 1\text{,}\) so \(B = -1\text{;}\) and setting \(n = -2\) gives \(2C = 1\text{,}\) so \(C = \frac12\text{.}\) Hence
      \begin{align*} \amp \sum_{n=1}^{\infty} \frac{1}{n(n+1)(n+2)} = \sum_{n=1}^{\infty} \frac12\left(\frac1n - \frac{2}{n+1} + \frac{1}{n+2}\right)\\ \amp = \frac12 \sum_{n=1}^{\infty} \left(\frac1n - \frac{1}{n+1}\right) - \frac12 \sum_{n=1}^{\infty} \left(\frac{1}{n+1} - \frac{1}{n+2}\right)\\ \amp = \frac12 \sum_{n=1}^{\infty} \left(\frac1n - \frac{1}{n+1}\right) - \frac12 \sum_{n=2}^{\infty} \left(\frac1n - \frac{1}{n+1}\right)\\ \amp = \frac12\left(1 - \frac12\right) + \underbrace{\frac12 \sum_{n=2}^{\infty} \left(\frac1n - \frac{1}{n+1}\right) - \frac12 \sum_{n=2}^{\infty} \left(\frac1n - \frac{1}{n+1}\right)}_{\text{zero}}\\ \amp = \frac14. \end{align*}
      🔗
      🔗
    2. This is a geometric series with \(a = 1\) and \(r = \frac{1}{e^2}\text{:}\)
      \begin{equation*} \sum_{n=0}^{\infty} e^{-2n} = \sum_{n=0}^{\infty} \left(\frac{1}{e^2}\right)^{n} = \sum_{n=1}^{\infty} \left(\frac{1}{e^2}\right)^{n-1} = \frac{1}{1 - \frac{1}{e^2}} = \frac{e^2}{e^2 - 1}. \end{equation*}
      🔗
      🔗
    3. This is a finite geometric sum. Using \(\displaystyle\sum_{n=1}^{N} ar^{n-1} = a\,\frac{1-r^{N}}{1-r}\text{,}\) which was proved when we first studied geometric sums,
      \begin{equation*} \sum_{n=0}^{10} e^{-2n} = \sum_{n=1}^{11} \left(\frac{1}{e^2}\right)^{n-1} = \frac{1 - \left(e^{-2}\right)^{11}}{1 - e^{-2}} = \frac{1 - e^{-22}}{1 - e^{-2}}. \end{equation*}
      🔗
      🔗
    4. \(\lim\limits_{n\to\infty} a_n = \lim\limits_{n\to\infty} e^{2n} = \infty\text{,}\) so by the \(n\)th Term Test the series diverges.
      🔗
      🔗
    5. Partial fractions give
      \begin{equation*} \frac{6}{(2n-1)(2n+1)} = \frac{A}{2n-1} + \frac{B}{2n+1} = \frac{A(2n+1) + B(2n-1)}{(2n-1)(2n+1)}, \end{equation*}
      and setting \(n = \frac12\) gives \(2A = 6\text{,}\) \(A = 3\text{,}\) while \(n = -\frac12\) gives \(-2B = 6\text{,}\) \(B = -3\text{.}\) The sum telescopes:
      \begin{align*} s_k \amp = \left(\frac11 - \frac13\right) + \left(\frac13 - \frac15\right) + \left(\frac15 - \frac17\right) + \cdots\\ \amp \quad + \left(\frac{1}{2k-1} - \frac{1}{2k+1}\right) = 1 - \frac{1}{2k+1},\\ \amp \phantom{=} \text{so} \quad 3\sum_{n=1}^{\infty} \left(\frac{1}{2n-1} - \frac{1}{2n+1}\right) = 3\lim_{k\to\infty} s_k\\ \amp \phantom{=} \qquad = 3\lim_{k\to\infty}\left(1 - \frac{1}{2k+1}\right) = 3. \end{align*}
      🔗
      🔗
    6. Partial fractions (or direct observation) give
      \begin{equation*} \frac{2n+1}{n^2(n+1)^2} = \frac{1}{n^2} - \frac{1}{(n+1)^2}, \end{equation*}
      so the sum telescopes:
      \begin{align*} s_k \amp = \sum_{n=1}^{k} \left(\frac{1}{n^2} - \frac{1}{(n+1)^2}\right)\\ \amp = \left(1 - \frac14\right) + \left(\frac14 - \frac19\right) + \left(\frac19 - \frac{1}{16}\right) + \cdots\\ \amp \quad + \left(\frac{1}{k^2} - \frac{1}{(k+1)^2}\right) = 1 - \frac{1}{(k+1)^2}\\ \amp \Rightarrow \quad \sum_{n=1}^{\infty} \frac{2n+1}{n^2(n+1)^2} = \lim_{k\to\infty} \left(1 - \frac{1}{(k+1)^2}\right) = 1. \end{align*}
      🔗
      🔗
    7. \(\lim\limits_{n\to\infty} \ln\!\left(\dfrac{n}{2n+1}\right) = \ln\!\left(\dfrac12\right) \ne 0\text{,}\) so by the \(n\)th Term Test the series diverges.
      🔗
      🔗
    8. Let \(L = \lim\limits_{n\to\infty} \left(1 + \frac4n\right)^{n}\text{.}\) Then
      \begin{align*} \ln L \amp = \lim_{n\to\infty} n \ln\!\left(1 + \frac4n\right) = \lim_{n\to\infty} \frac{\ln\!\left(1 + \frac4n\right)}{\frac1n}\\ \amp \;\overset{\text{H}}{=}\; \lim_{n\to\infty} \frac{\dfrac{-4/n^2}{1 + 4/n}}{-\dfrac{1}{n^2}} = \lim_{n\to\infty} \frac{4}{1 + \frac4n} = 4. \end{align*}
      Hence \(L = e^4 \ne 0\text{,}\) so by the \(n\)th Term Test the series diverges.
      🔗
      🔗
    9. \begin{equation*} \sum_{n=2}^{\infty} \frac{2}{3^n} = \sum_{n=2}^{\infty} 2\left(\frac13\right)^{n} = \frac{2}{1-\frac13} - \left(2 + \frac23\right) = 3 - \frac83 = \frac13, \end{equation*}
      where the terms for \(n = 0\) and \(n = 1\) need to be subtracted.
      🔗
      🔗
    10. \begin{align*} \sum_{n=3}^{\infty} \frac{2^n}{3^n} \amp = \sum_{n=4}^{\infty} \left(\frac23\right)^{n-1} = \frac{1}{1-\frac23} - \left(\frac49 + \frac23 + 1\right)\\ \amp = 3 - \frac{4+6+9}{9} = 3 - \frac{19}{9} = \frac{27-19}{9} = \frac89, \end{align*}
      where the subtracted terms correspond to \(n = 3\text{,}\) \(n = 2\text{,}\) and \(n = 1\) of the shifted series.
      🔗
      🔗

    7.

    The government has decided to give a $1,000 tax rebate to each household in order to stimulate the economy. The government statistics say that each household will spend 80% of the rebate in goods and services. The businesses and individuals who benefited from that 80% will then spend 80% of what they received and so on. The result is called the multiplier effect. What is the total effect of the rebate on the economy?
    🔗
    Solution.
    The rounds of spending form a geometric series with \(a = 1000\) and \(r = 0.8\text{:}\)
    \begin{align*} \amp 1000 + 0.8(1000) + (0.8)^2(1000) + \cdots = \sum_{n=1}^{\infty} 1000\,(0.8)^{n-1}\\ \amp = \frac{1000}{1 - 0.8} = \frac{1000}{0.2} = 5000 \text{ dollars}. \end{align*}
    The successive rounds of spending are shown in Figure 22.1.

    8.

    Answer questions A and B below for the following infinite series:
    \begin{equation*} \sum_{k=1}^{\infty} \left(\frac{6}{k^2} - \frac{6}{(k+1)^2}\right). \end{equation*}
    1. Does the \(n\)th-term test apply? Remember to fully justify your answer.
      🔗
      🔗
    2. Evaluate the series or show that it diverges.
      🔗
      🔗
    🔗
    Solution.
    1. We compute the limit of the terms:
      \begin{align*} \lim_{n\to\infty} a_n \amp = \lim_{n\to\infty} \frac{6}{n^2} - \frac{6}{(n+1)^2} = \lim_{n\to\infty} \frac{6(n+1)^2 - 6n^2}{n^2(n+1)^2}\\ \amp = \lim_{n\to\infty} \frac{12n + 6}{n^2(n+1)^2} = \lim_{n\to\infty} \frac{12n}{n^4} = 0. \end{align*}
      Hence the \(n\)th-term test does not apply: since the limit of the terms is \(0\text{,}\) the test is inconclusive.
      🔗
      🔗
    2. The series telescopes. The partial sum is
      \begin{align*} s_n \amp = \left(\frac{6}{1^2} - \frac{6}{2^2}\right) + \left(\frac{6}{2^2} - \frac{6}{3^2}\right) + \cdots\\ \amp \quad + \left(\frac{6}{(n-1)^2} - \frac{6}{n^2}\right) + \left(\frac{6}{n^2} - \frac{6}{(n+1)^2}\right)\\ \amp = 6 - \frac{6}{(n+1)^2}, \end{align*}
      and therefore
      \begin{equation*} \sum_{k=1}^{\infty} \left(\frac{6}{k^2} - \frac{6}{(k+1)^2}\right) = \lim_{n\to\infty} s_n = \lim_{n\to\infty} 6 - \frac{6}{(n+1)^2} = 6 - 0 = 6. \end{equation*}

    9.

    Determine whether the series is convergent or divergent and if it is convergent calculate its sum.
    1. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} \sin\!\left(\frac{1}{n+1}\right) - \sin\!\left(\frac{1}{n+2}\right)\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} \frac{1 + 5^n}{3^n}\)
      🔗
      🔗
    🔗
    Solution.
    1. The series telescopes. The partial sum is
      \begin{align*} s_k \amp = \sum_{n=0}^{k} \sin\!\left(\frac{1}{n+1}\right) - \sin\!\left(\frac{1}{n+2}\right)\\ \amp = \sin(1) - \sin\!\left(\frac12\right) + \sin\!\left(\frac12\right) - \sin\!\left(\frac13\right)\\ \amp \quad + \sin\!\left(\frac13\right) - \sin\!\left(\frac14\right) + \cdots\\ \amp \quad + \sin\!\left(\frac{1}{k+1}\right) - \sin\!\left(\frac{1}{k+2}\right)\\ \amp = \sin(1) - \sin\!\left(\frac{1}{k+2}\right). \end{align*}
      Hence the series converges and
      \begin{align*} \sum_{n=0}^{\infty} \sin\!\left(\frac{1}{n+1}\right) - \sin\!\left(\frac{1}{n+2}\right) \amp = \lim_{k\to\infty} s_k\\ \amp = \sin(1) - \sin(0) = \sin(1). \end{align*}
      🔗

    2. We split the series into two geometric series:
      \begin{equation*} \sum_{n=0}^{\infty} \frac{1 + 5^n}{3^n} = \sum_{n=0}^{\infty} \left(\frac13\right)^{n} + \sum_{n=0}^{\infty} \left(\frac53\right)^{n}. \end{equation*}
      Since \(\lim\limits_{n\to\infty} \left(\frac53\right)^{n} = \infty\text{,}\) by the \(n\)th term test we can conclude that the series diverges.

    10.

    Determine whether the series converges, and if so find its sum:
    \begin{equation*} \sum_{n=1}^{\infty} \left(\frac{n}{n+5}\right)^{n}. \end{equation*}
    🔗
    Solution.
    Note that
    \begin{equation*} \lim_{n\to\infty} a_n = \lim_{n\to\infty} \left(1 + \frac5n\right)^{-n} = \lim_{n\to\infty} \left[\left(1 + \frac5n\right)^{\frac{n}{5}}\right]^{-5} = e^{-5} \ne 0, \end{equation*}
    since \(\left(1 + \frac5n\right)^{n/5} \to e\text{.}\) Indeed, setting \(x = \frac{n}{5}\) and \(L = \lim\limits_{x\to\infty}\left(1 + \frac1x\right)^{x}\text{,}\)
    \begin{align*} \ln L \amp = \lim_{x\to\infty} x \ln\!\left(1 + \frac1x\right) = \lim_{x\to\infty} \frac{\ln\!\left(1 + \frac1x\right)}{\frac1x}\\ \amp \;\overset{\text{H}}{=}\; \lim_{x\to\infty} \frac{\dfrac{-1/x^2}{1 + 1/x}}{-\dfrac{1}{x^2}} = \lim_{x\to\infty} \frac{1}{1 + \frac1x} = 1\\ \amp \;\Rightarrow\; L = e. \end{align*}
    Therefore, the series diverges by the \(n\)th Term Test.

    11.

    Consider the following series. Answer the following questions.
    \begin{equation*} \sum_{n=0}^{\infty} \frac{(x+4)^n}{2^n} \end{equation*}
    1. Find the values of \(x\) for which the series converges.
      🔗
      🔗
    2. Find the sum of the series for those values of \(x\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. We can write the series as a geometric series:
      \begin{equation*} \sum_{n=0}^{\infty} \frac{(x+4)^n}{2^n} = \sum_{n=0}^{\infty} \left(\frac{x+4}{2}\right)^{n} = \sum_{n=0}^{\infty} \left(\frac{x}{2}+2\right)^{n}, \end{equation*}
      which converges when \(\left|\frac{x}{2} + 2\right| \lt 1\text{:}\)
      \begin{equation*} -1 \lt \frac{x}{2} + 2 \lt 1 \;\Rightarrow\; -3 \lt \frac{x}{2} \lt -1 \;\Rightarrow\; -6 \lt x \lt -2, \end{equation*}
      i.e. the series converges on the interval \((-6, -2)\text{.}\)
      🔗
      🔗
    2. When \(x \in (-6,-2)\text{,}\) the geometric series with \(a = 1\) and \(r = \frac{x+4}{2}\) gives
      \begin{equation*} \sum_{n=0}^{\infty} \left(\frac{x+4}{2}\right)^{n} = \frac{1}{1 - \frac{x+4}{2}} = \frac{2}{2 - x - 4} = -\frac{2}{x+2}. \end{equation*}

    14.

    Consider the series \(\displaystyle\sum_{k=0}^{\infty} \frac{3^{k-1}}{5^k}\text{.}\) Does the series converge? If so, what is the result?
    🔗
    Solution.
    We first factor out \(\frac13\) so that the powers match:
    \begin{equation*} \sum_{k=0}^{\infty} \frac{3^{k-1}}{5^k} = \frac13 \sum_{k=0}^{\infty} \frac{3^{k}}{5^k} = \frac13 \sum_{k=0}^{\infty} \left(\frac35\right)^{k}. \end{equation*}
    Splitting off the \(k = 0\) term so that the sum starts at \(k = 1\text{,}\)
    \begin{equation*} \frac13 \sum_{k=0}^{\infty} \left(\frac35\right)^{k} = \frac13\left[1 + \sum_{k=1}^{\infty} \left(\frac35\right)\left(\frac35\right)^{k-1}\right]. \end{equation*}
    🔗
    The remaining sum is a geometric series with \(a = \frac35\) and \(r = \frac35\text{.}\) Since \(|r| = \frac35 \lt 1\text{,}\) it converges and \(\displaystyle\sum_{k=1}^{\infty} ar^{k-1} = \frac{a}{1-r}\text{,}\) so
    \begin{equation*} \frac13\left[1 + \frac{\frac35}{1 - \frac35}\right] = \frac13\left[1 + \frac32\right] = \frac13 \cdot \frac52 = \frac56. \end{equation*}

    15.

    Find the sum of all of the convergent series.
    1. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} \frac{\sin\!\left(\frac{\pi}{2}n\right)}{3^{n+1}}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{-2}{n(n+1)}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} \frac{(-25)^n}{(2n)!}\)
      🔗
      🔗
    🔗
    Solution.
    1. The factor \(\sin\!\left(\frac{\pi}{2}n\right)\) cycles through \(0, 1, 0, -1\) as \(n = 0, 1, 2, 3, \ldots\text{,}\) so only the odd \(n\) contribute, with alternating signs. Writing \(n = 2k+1\text{,}\)
      \begin{equation*} \sum_{n=0}^{\infty} \frac{\sin\!\left(\frac{\pi}{2}n\right)}{3^{n+1}} = \frac{1}{3^2} - \frac{1}{3^4} + \frac{1}{3^6} - \cdots = \sum_{k=0}^{\infty} \frac{(-1)^k}{3^{2k+2}} = \frac19 \sum_{k=0}^{\infty}\left(-\frac19\right)^{k}. \end{equation*}
      This is a geometric series with \(a = 1\) and \(r = -\frac19\text{,}\) and \(|r| \lt 1\text{,}\) so
      \begin{equation*} \frac19 \cdot \frac{1}{1 - \left(-\frac19\right)} = \frac19 \cdot \frac{1}{\frac{10}{9}} = \frac{1}{10}. \end{equation*}
      🔗
      🔗
    2. By the constant multiple rule, \(\displaystyle\sum_{n=1}^{\infty} \frac{-2}{n(n+1)} = -2\sum_{n=1}^{\infty} \frac{1}{n(n+1)}\text{.}\) The remaining series telescopes: since \(\dfrac{1}{n(n+1)} = \dfrac1n - \dfrac{1}{n+1}\text{,}\)
      \begin{equation*} s_n = \left(1 - \frac12\right) + \left(\frac12 - \frac13\right) + \cdots + \left(\frac1n - \frac{1}{n+1}\right) = 1 - \frac{1}{n+1} \;\longrightarrow\; 1. \end{equation*}
      Hence the sum is \(-2(1) = -2\text{.}\)
      🔗
      🔗
    3. Recall \(\cos x = \displaystyle\sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!}\text{.}\) With \(x = 5\text{,}\)
      \begin{equation*} \cos(5) = \sum_{n=0}^{\infty} \frac{(-1)^n 5^{2n}}{(2n)!} = \sum_{n=0}^{\infty} \frac{(-1)^n 25^{n}}{(2n)!} = \sum_{n=0}^{\infty} \frac{(-25)^{n}}{(2n)!}, \end{equation*}
      so the sum is \(\cos(5)\text{.}\)
