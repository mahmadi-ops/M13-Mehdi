    Worksheet 22.17 Exercises for Directional Derivatives and Gradient Vectors
    

    These problems use the gradient to compute directional derivatives and directions of fastest change. If you would like to review this topic first, see Directional Derivatives and Gradient Vectors.
    🔗

    1.

    Consider \(f(x,y) = e^{-r^4}\) where \(r = \sqrt{x^2+y^2}\text{.}\) Compute its directional derivative at \((0,0)\) with respect to the unit vectors in (polar) directions \(\theta = 0, \dfrac{\pi}{4}, \dfrac{\pi}{2}\text{.}\) What about any other angle?
    🔗
    Solution.
    The function is symmetric with respect to rotations around the origin, so all the directional derivatives will be equal. Therefore it is sufficient to compute the derivative for \(\theta = 0\text{,}\) i.e. \(\dfrac{\partial f}{\partial x}\text{:}\)
    \begin{equation*} \frac{\partial f}{\partial x} = \frac{\partial}{\partial x} e^{-(x^2+y^2)^2} = -2(x^2+y^2)\cdot 2x\, e^{-(x^2+y^2)^2}. \end{equation*}
    Plugging in \(x = y = 0\) we see that this is zero. Hence the directional derivative at \((0,0)\) is \(0\) in the directions \(\theta = 0, \dfrac{\pi}{4}, \dfrac{\pi}{2}\text{,}\) and by the same symmetry it is \(0\) for every other angle as well.
    🔗
    🔗
    🔗

    2.

    Find all points at which the direction of fastest change of the function \(f(x,y) = x^2 + y^2 - 2x - 4y\) is \(\langle 1, 1\rangle\text{.}\)
    🔗
    Solution.
    The direction of fastest change is \(\nabla f(x,y) = \langle 2x-2,\, 2y-4\rangle\text{,}\) so we need to find all points \((x,y)\) such that \(\nabla f(x,y) = k\langle 1,1\rangle\text{.}\) Then
    \begin{equation*} 2x - 2 = k \quad\text{and}\quad 2y - 4 = k, \end{equation*}
    so
    \begin{equation*} 2x - 2 = 2y - 4 \;\Rightarrow\; y = x + 1. \end{equation*}
    Hence, the direction of fastest change is \(\langle 1,1\rangle\) at all points on the line \(y = x + 1\text{.}\) See Figure 22.61.
    🔗
    🔗
    🔗

    3. True or False.

      If \(\vec u = \langle a, b\rangle\) is a unit vector and \(f\) has continuous second partials, then
      \begin{equation*} D^2_{\vec u} f(x,y) = f_{xx}a^2 + 2f_{xy}ab + f_{yy}b^2, \end{equation*}
      where \(D^2_{\vec u} f = D_{\vec u}\left[D_{\vec u} f(x,y)\right]\text{.}\)
      🔗

    • True.

    • We have that
      \begin{equation*} D^2_{\vec u} f = D_{\vec u}\left[D_{\vec u} f(x,y)\right] = D_{\vec u}\left[a f_x + b f_y\right]. \end{equation*}
      This simplifies to
      \begin{equation*} \langle a f_{xx} + b f_{xy},\; a f_{xy} + b f_{yy}\rangle \cdot \langle a, b\rangle = f_{xx}a^2 + 2f_{xy}ab + f_{yy}b^2. \end{equation*}
      Note we needed \(f\) to have continuous second partials to invoke Clairaut’s Theorem.

    • False.

    • We have that
      \begin{equation*} D^2_{\vec u} f = D_{\vec u}\left[D_{\vec u} f(x,y)\right] = D_{\vec u}\left[a f_x + b f_y\right]. \end{equation*}
      This simplifies to
      \begin{equation*} \langle a f_{xx} + b f_{xy},\; a f_{xy} + b f_{yy}\rangle \cdot \langle a, b\rangle = f_{xx}a^2 + 2f_{xy}ab + f_{yy}b^2. \end{equation*}
      Note we needed \(f\) to have continuous second partials to invoke Clairaut’s Theorem.
    🔗

    4. True or False.

      \(D_{\vec i + \vec j}\,f(x,y) = f_x + f_y\text{.}\)
      🔗

    • True.

    • Since \(\vec i + \vec j = \langle 1, 1\rangle\text{,}\)
      \begin{equation*} D_{\vec i + \vec j}\,f(x,y) = \nabla f(x,y) \cdot \langle 1, 1\rangle = f_x + f_y. \end{equation*}

    • False.

    • Since \(\vec i + \vec j = \langle 1, 1\rangle\text{,}\)
      \begin{equation*} D_{\vec i + \vec j}\,f(x,y) = \nabla f(x,y) \cdot \langle 1, 1\rangle = f_x + f_y. \end{equation*}
    🔗

    5. A mountain lion on a mountain.

    A mountain lion runs on a mountain whose height above the point \((x,y)\) is \(z = x^2 + \sin^2(xy)\text{.}\)
    1. In which direction(s) should the mountain lion run from point \((1, 0, 1)\) so that the height is increasing at the fastest possible rate? What is this fastest rate?
      🔗
      🔗
    2. In which direction(s) should the mountain lion run from point \((1, 0, 1)\) so that the height is increasing at half of the fastest possible rate?
      🔗
      🔗
    🔗
    Solution.
    1. The fastest possible rate of increase is attained in the direction of the gradient:
      \begin{equation*} \nabla z = \left\langle \frac{\partial z}{\partial x}, \frac{\partial z}{\partial y}\right\rangle = \left\langle 2x + 2\sin(xy)\cos(xy)\,y,\; 2\sin(xy)\cos(xy)\,x\right\rangle. \end{equation*}
      At \((1, 0, 1)\text{,}\) this gradient is simply \(\nabla z(1,0) = \langle 2, 0\rangle\text{,}\) and the fastest possible rate of change is the length of the gradient, i.e. \(|\nabla z(1,0)| = |\langle 2,0\rangle| = 2\text{.}\)
      🔗
      🔗
    2. Half of the fastest possible rate of height increase at point \((1,0,1)\) is \(\frac12 \cdot 2 = 1\text{.}\) Let \(\vec u = \langle a, b\rangle\) be a unit vector in the desired direction. Then the directional derivative \(D_{\vec u}(1,0) = 1\) is the desired rate of change of height at \((1,0,1)\) in the direction of \(\vec u\text{;}\) it can be calculated using the dot product with the gradient:
      \begin{equation*} 1 = D_{\vec u}(1,0) = \vec u \cdot \nabla z(1,0) = \langle a, b\rangle \cdot \langle 2, 0\rangle = 2a + 0b = 2a. \end{equation*}
      Thus, \(a = \frac12\) and \(b\) must be such that \(\vec u = \left\langle \frac12, b\right\rangle\) is unit, i.e. \(\left(\frac12\right)^2 + b^2 = 1\text{,}\) from which \(b^2 = \frac34\) and \(b = \pm\frac{\sqrt3}{2}\text{.}\) Therefore, the desired directions in which the height is increasing at a rate equal to half of the fastest possible rate are \(\vec u_1 = \left\langle \frac12, \frac{\sqrt3}{2}\right\rangle\) and \(\vec u_2 = \left\langle \frac12, -\frac{\sqrt3}{2}\right\rangle\text{.}\)
      🔗
      🔗
    🔗
    🔗

    6.

    A metal plate is placed on the \(xy\)-plane in such a way that the temperature \(T\) at any point \((x,y)\) is given by \(T = e^x(\sin x + \sin y)\) °C.
    1. What is the rate of change in temperature at \((0,0)\) in the direction of \(3\,\mathbf i - 4\,\mathbf j\text{?}\)
      🔗
      🔗
    2. At \((0,0)\text{,}\) in what direction is the temperature increasing most rapidly?
      🔗
      🔗
    3. At \((0,0)\text{,}\) in what direction is the temperature decreasing most rapidly?
      🔗
      🔗
    🔗
    Solution.
    1. We first compute the gradient:
      \begin{align*} T_x \amp = e^x(\sin x + \sin y) + e^x\cos x\\ \amp = e^x(\sin x + \cos x + \sin y), \qquad T_x(0,0) = 1,\\ T_y \amp = e^x \cos y, \qquad T_y(0,0) = 1, \end{align*}
      so \(\nabla T\big|_{(0,0)} = \langle 1, 1\rangle\text{.}\) The direction vector is \(\vec u = \langle 3, -4\rangle\) with \(\|\vec u\| = \sqrt{9 + 16} = 5\text{,}\) so the unit vector is \(\hat u = \dfrac{\vec u}{\|\vec u\|} = \left\langle \dfrac35, -\dfrac45\right\rangle\text{.}\) Hence
      \begin{equation*} \left(D_{\hat u} T\right)_{(0,0)} = \nabla T\big|_{(0,0)} \cdot \hat u = \langle 1, 1\rangle \cdot \left\langle \frac35, -\frac45\right\rangle = -\frac15. \end{equation*}
      🔗
      🔗
    2. The temperature increases most rapidly in the direction of the gradient:
      \begin{equation*} \hat u = \frac{\nabla T\big|_{(0,0)}}{\left\|\nabla T\big|_{(0,0)}\right\|} = \left\langle \frac{1}{\sqrt2}, \frac{1}{\sqrt2}\right\rangle. \end{equation*}
      🔗
      🔗
    3. The temperature decreases most rapidly in the direction opposite to the gradient:
      \begin{equation*} \hat u = -\frac{\nabla T\big|_{(0,0)}}{\left\|\nabla T\big|_{(0,0)}\right\|} = \left\langle -\frac{1}{\sqrt2}, -\frac{1}{\sqrt2}\right\rangle. \end{equation*}
      🔗
      🔗
    🔗

    7.

    Suppose that \(f(x,y,z)\) is a function of three variables and let
    \begin{equation*} \hat u = \frac{1}{\sqrt2}\langle 1, -1, 0\rangle, \qquad \hat v = \frac{1}{\sqrt2}\langle 1, 0, -1\rangle, \qquad \hat w = \langle 0, 0, 1\rangle. \end{equation*}
    Suppose that at a point \(P_0(a,b,c)\text{,}\)
    \begin{align*} \left(D_{\hat u} f\right)_{P_0} \amp = 0,\\ \left(D_{\hat v} f\right)_{P_0} \amp = 0,\\ \left(D_{\hat w} f\right)_{P_0} \amp = 1. \end{align*}
    1. Find the direction of the maximum rate of change at \(P_0(a,b,c)\text{.}\)
      🔗
      🔗
    2. Find the maximum rate of change at \(P_0(a,b,c)\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. Using \(\left(D_{\hat u} f\right)_{P_0} = \nabla f\big|_{P_0}\cdot\hat u\text{,}\) the three conditions become
      \begin{gather*} \left(D_{\hat u} f\right)_{P_0} = 0 \;\Rightarrow\; \langle f_x, f_y, f_z\rangle \cdot \frac{1}{\sqrt2}\langle 1, -1, 0\rangle = \frac{1}{\sqrt2}\left(f_x - f_y\right) = 0\\ \qquad \Rightarrow\; f_x = f_y,\\ \left(D_{\hat v} f\right)_{P_0} = 0 \;\Rightarrow\; \langle f_x, f_y, f_z\rangle \cdot \frac{1}{\sqrt2}\langle 1, 0, -1\rangle = \frac{1}{\sqrt2}\left(f_x - f_z\right) = 0\\ \qquad \Rightarrow\; f_x = f_z,\\ \left(D_{\hat w} f\right)_{P_0} = 1 \;\Rightarrow\; \langle f_x, f_y, f_z\rangle \cdot \langle 0, 0, 1\rangle = f_z = 1. \end{gather*}
      Hence \(\nabla f\big|_{P_0} = \langle 1, 1, 1\rangle\text{,}\) and the direction of the maximum rate of change at \(P_0\) is given by
      \begin{equation*} \hat u = \frac{\nabla f\big|_{P_0}}{\left\|\nabla f\big|_{P_0}\right\|} = \frac{1}{\sqrt3}\langle 1, 1, 1\rangle. \end{equation*}
      🔗
      🔗
    2. \(\left\|\nabla f\big|_{P_0}\right\| = \sqrt{1 + 1 + 1} = \sqrt3\) is the maximum rate of change.
      🔗
      🔗

    8.

    Calculate the maximum rate of change of \(f(x,y) = \ln(x^2+y^2)\) at the point \((-4, 3)\) and determine the direction in which it occurs.
    🔗
    Solution.
    The gradient is
    \begin{equation*} \nabla f = \left(\frac{2x}{x^2+y^2}\right)\mathbf i + \left(\frac{2y}{x^2+y^2}\right)\mathbf j, \end{equation*}
    so at \((-4,3)\text{,}\)
    \begin{align*} \nabla f(-4,3) \amp = \left(-\frac{8}{25}\right)\mathbf i + \left(\frac{6}{25}\right)\mathbf j,\\ |\nabla f(-4,3)| \amp = \sqrt{\frac{100}{(25)^2}} = \frac{10}{25} = \frac25. \end{align*}
    The direction of maximum increase is
    \begin{equation*} \hat u = \frac{\nabla f(-4,3)}{|\nabla f(-4,3)|} = \left(-\frac45\right)\mathbf i + \left(\frac35\right)\mathbf j, \end{equation*}
    and the maximum rate of increase is
    \begin{equation*} \left(D_{\hat u} f\right)_{P_0} = |\nabla f(-4,3)| = \frac25. \end{equation*}
    🔗
    🔗
    🔗

    9.

    Consider the function \(f(x,y) = x^2 e^{3y}\) and the point \(P_0 = (-1, 0)\text{.}\)
    1. Find the direction in which \(f(x,y)\) decreases the most rapidly at \(P_0\text{.}\)
      🔗
      🔗
    2. Find the directional derivative of \(f(x,y)\) at \(P_0\) in the direction given by \(\vec v = \langle -1, 1\rangle\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    The gradient is
    \begin{align*} \nabla f \amp = \left(2x e^{3y}\right)\mathbf i + \left(3x^2 e^{3y}\right)\mathbf j,\\ \nabla f\big|_{(-1,0)} \amp = -2\,\mathbf i + 3\,\mathbf j, \qquad \left\|\nabla f\big|_{(-1,0)}\right\| = \sqrt{13}. \end{align*}
    1. The direction of most rapid decrease is opposite to the gradient:
      \begin{equation*} -\frac{\nabla f}{\|\nabla f\|} = \left(\frac{2}{\sqrt{13}}\right)\mathbf i - \left(\frac{3}{\sqrt{13}}\right)\mathbf j = \left\langle \frac{2}{\sqrt{13}}, -\frac{3}{\sqrt{13}} \right\rangle. \end{equation*}
      🔗
      🔗
    2. The unit vector in the direction of \(\vec v\) is \(\hat u = \dfrac{\vec v}{\|\vec v\|} = \left\langle -\dfrac{1}{\sqrt2}, \dfrac{1}{\sqrt2}\right\rangle\text{,}\) so
      \begin{equation*} D_{\hat u} f = \nabla f \cdot \hat u = \langle -2, 3\rangle \cdot \left\langle -\frac{1}{\sqrt2}, \frac{1}{\sqrt2}\right\rangle = \frac{5}{\sqrt2}. \end{equation*}
      🔗
      🔗
    🔗
    🔗

    10.

    Consider the function \(f(x,y) = x^2 + xy + y^2\text{.}\)
    1. Find the directions in which \(f(x,y)\) increases and decreases most rapidly at \(P_0(-1,1)\text{.}\)
      🔗
      🔗
    2. Find the derivatives of \(f(x,y)\) in these directions at \(P_0(-1,1)\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. The gradient is
      \begin{align*} \nabla f \amp = (2x + y)\,\mathbf i + (x + 2y)\,\mathbf j,\\ \left(\nabla f\right)_{(-1,1)} \amp = \langle -1, 1\rangle, \qquad \left|\left(\nabla f\right)_{(-1,1)}\right| = \sqrt2. \end{align*}
      The function increases most rapidly in the direction of the gradient,
      \begin{equation*} \hat u_1 = \frac{\left(\nabla f\right)_{(-1,1)}} {\left|\left(\nabla f\right)_{(-1,1)}\right|} = \left\langle -\frac{1}{\sqrt2}, \frac{1}{\sqrt2}\right\rangle, \end{equation*}
      and decreases most rapidly in the opposite direction,
      \begin{equation*} \hat u_2 = -\frac{\left(\nabla f\right)_{(-1,1)}} {\left|\left(\nabla f\right)_{(-1,1)}\right|} = \left\langle \frac{1}{\sqrt2}, -\frac{1}{\sqrt2}\right\rangle. \end{equation*}
      🔗
      🔗
    2. The directional derivatives are
      \begin{align*} \left(D_{\hat u_1} f\right)_{P_0} \amp = \left(\nabla f\right)_{(-1,1)} \cdot \hat u_1 = \frac{1}{\sqrt2} + \frac{1}{\sqrt2} = \sqrt2 = \left|\left(\nabla f\right)_{(-1,1)}\right|,\\ \left(D_{\hat u_2} f\right)_{P_0} \amp = \left(\nabla f\right)_{(-1,1)} \cdot \hat u_2 = -\frac{1}{\sqrt2} - \frac{1}{\sqrt2} = -\sqrt2 = -\left|\left(\nabla f\right)_{(-1,1)}\right|. \end{align*}
      As expected, the largest possible rate of change is \(|\nabla f|\) and the smallest is \(-|\nabla f|\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    11.

    Suppose the temperature (in degrees Celsius) at a point \((x,y,z)\) is given by \(T(x,y,z)\text{,}\) where \(T\) is a continuous function that has continuous partial derivatives, and distances in \(xyz\)-space are measured in meters. We are given the following information about \(T\) at the point \((x,y,z) = (1,1,1)\text{:}\)
    • \(T(1,1,1) = 20\) °C,
      🔗
      🔗
    • the derivative of \(T\) at \((1,1,1)\) obtains its smallest (i.e. most negative) value in the direction toward the point \((-1, 2, -3)\text{,}\)
      🔗
      🔗
    • the derivative of \(T\) at \((1,1,1)\) in the direction of the vector \(-\mathbf i + 2\,\mathbf j + 2\,\mathbf k\) is \(2\) °C/m.
      🔗
      🔗
    1. Find the derivative of \(T\) at \((1,1,1)\) in the direction toward the point \((-2, 1, 5)\text{.}\)
      🔗
      🔗
    2. If you start at \((1,1,1)\) and move along a straight path toward the point \((-2,1,5)\text{,}\) approximately how far will you have to go in this direction until the temperature reaches \(24\) °C?
      🔗
      🔗
    🔗
    Solution.
    First we determine \(\nabla T\) at \((1,1,1)\text{.}\) The derivative is most negative in the direction of \(-\nabla T\text{,}\) and the direction from \((1,1,1)\) toward \((-1,2,-3)\) is
    \begin{equation*} \langle -1-1,\; 2-1,\; -3-1\rangle = \langle -2, 1, -4\rangle. \end{equation*}
    Hence \(-\nabla T\) is a positive multiple of \(\langle -2, 1, -4\rangle\text{,}\) i.e. \(\nabla T = c\,\langle 2, -1, 4\rangle\) for some \(c \gt 0\text{.}\)
    🔗
    The third piece of information fixes \(c\text{.}\) The unit vector in the direction of \(-\mathbf i + 2\,\mathbf j + 2\,\mathbf k\) is \(\frac13\langle -1, 2, 2\rangle\text{,}\) since \(|\langle -1,2,2\rangle| = 3\text{,}\) so
    \begin{equation*} 2 = \nabla T \cdot \frac13\langle -1, 2, 2\rangle = \frac{c}{3}\Big(-2 - 2 + 8\Big) = \frac{4c}{3} \;\Rightarrow\; c = \frac32. \end{equation*}
    Therefore
    \begin{equation*} \nabla T\big|_{(1,1,1)} = \frac32\langle 2, -1, 4\rangle = \left\langle 3, -\frac32, 6\right\rangle. \end{equation*}
    🔗
    1. The direction from \((1,1,1)\) toward \((-2,1,5)\) is \(\langle -3, 0, 4\rangle\text{,}\) whose length is \(5\text{,}\) so the unit vector is \(\hat u = \left\langle -\frac35, 0, \frac45\right\rangle\) and
      \begin{equation*} \left(D_{\hat u} T\right)_{(1,1,1)} = \left\langle 3, -\frac32, 6\right\rangle \cdot \left\langle -\frac35, 0, \frac45\right\rangle = -\frac95 + \frac{24}{5} = 3 \; {}^{\circ}\text{C}/\text{m}. \end{equation*}
      🔗
      🔗
    2. The temperature must rise from \(20\) °C to \(24\) °C, i.e. \(\Delta T = 4\) °C, and along this direction it rises at approximately \(3\) °C per meter. Using the linear approximation \(\Delta T \approx \left(D_{\hat u}T\right) \cdot s\text{,}\) where \(s\) is the distance travelled,
      \begin{equation*} s \approx \frac{\Delta T}{D_{\hat u}T} = \frac43 \approx 1.33 \text{ meters}. \end{equation*}
      🔗
      🔗
    🔗

    12.

    In \(xyz\)-space, the temperature at the point \((x,y,z)\) is given by \(T(x,y,z) = 4xy + 3z^2\text{.}\) You’re at \((2,0,1)\) where the temperature is \(3^{\circ}\text{.}\) Brrrr!
    1. In what direction should you go, from \((2,0,1)\text{,}\) in order to warm up the fastest?
      🔗
      🔗
    2. What is the directional derivative in that direction at the point \((2,0,1)\text{?}\)
      🔗
      🔗
    3. If you walk \(0.2\) units in that direction, by about how many degrees will you warm up?
      🔗
      🔗
    🔗
    Solution.
    1. A function increases fastest in the direction of its gradient:
      \begin{equation*} \nabla T = \langle 4y, 4x, 6z\rangle, \qquad \nabla T\big|_{(2,0,1)} = \langle 0, 8, 6\rangle = 8\,\mathbf j + 6\,\mathbf k. \end{equation*}
      So head in the direction \(8\,\mathbf j + 6\,\mathbf k\) (equivalently, the unit vector \(\left\langle 0, \frac45, \frac35\right\rangle\)).
      🔗
      🔗
    2. In the direction of the gradient, the directional derivative equals the length of the gradient:
      \begin{equation*} \left(D_{\hat u}T\right)_{(2,0,1)} = \left|\nabla T\big|_{(2,0,1)}\right| = \sqrt{64 + 36} = 10. \end{equation*}
      🔗
      🔗
    3. The directional derivative is the rate of change of temperature per unit of distance travelled, so by the linear approximation
      \begin{equation*} \Delta T \approx \left(D_{\hat u}T\right) \cdot s = 10 \times 0.2 = 2^{\circ}. \end{equation*}

      🔗

    13.

    \(f\) is a “nice” function of \(x\) and \(y\) (i.e. \(f\) is continuous and its partials exist). In Figure 22.62 are shown the level curves \(f(x,y) = 0, 2, 4, 6, 8, 10, 12\text{.}\)
    1. Let \(u_1 = \frac{1}{\sqrt2}\mathbf i + \frac{1}{\sqrt2}\mathbf j\text{.}\) Estimate \(D_{u_1}f(4,3)\text{.}\)
      🔗
      🔗
    2. Estimate \(D_{u_1}f(1,2)\text{.}\)
      🔗
      🔗
    3. Draw on the diagram a unit vector pointing in the same direction as \(\nabla f(1,2)\text{.}\)
      🔗
      🔗
    4. At \(P\text{,}\) draw a unit vector and label it \(u_2\text{,}\) such that \(D_{u_2}f(P) \lt 0\text{.}\)
      🔗
      🔗
    5. Estimate \(\dfrac{\partial f}{\partial x}(P)\text{.}\)
      🔗
      🔗
    6. Which appears bigger, \(\dfrac{\partial f}{\partial y}(Q)\) or \(\dfrac{\partial f}{\partial y}(R)\text{?}\)
      🔗
      🔗
    🔗
    Solution.
    1. The directional derivative \(D_{u_1}f(4,3)\) tells us roughly how much \(f\) increases if we move one unit from \((4,3)\) in the direction \(u_1\text{,}\) i.e. diagonally up and to the right at \(45^{\circ}\text{.}\) Starting at \((4,3)\) and moving one unit that way lands us near \((4.7, 3.7)\text{,}\) which is about two contours further along, and each contour step is \(\Delta f = 2\) spread over roughly one unit of travel. Reading the map,
      \begin{equation*} D_{u_1}f(4,3) \approx 2. \end{equation*}
      🔗
      🔗
    2. At \((1,2)\) the level curve through that point is climbing at roughly \(45^{\circ}\text{,}\) i.e. the level curve is parallel to \(u_1\text{.}\) Moving along a level curve does not change the value of \(f\text{,}\) so
      \begin{equation*} D_{u_1}f(1,2) \approx 0. \end{equation*}
      🔗
      🔗
    3. The gradient is perpendicular to the level curve and points in the direction of increase. At \((1,2)\) the level curve runs up and to the right at about \(45^{\circ}\text{,}\) and \(f\) increases as we move upward, so \(\nabla f(1,2)\) points up and to the left, i.e. in the direction \(\frac{1}{\sqrt2}\langle -1, 1\rangle\text{.}\) See Figure 22.63.
      🔗
      🔗
    4. We need any direction of decrease at \(P\text{,}\) i.e. any direction pointing toward the lower-valued level curves (toward \(f = 10\text{,}\) not away from it). Since the level curves below \(P\) have smaller values, \(u_2 = \langle 0, -1\rangle\) (straight down) works. See Figure 22.63.
      🔗
      🔗
    5. \(P\) sits at the very top of its level curve, where the curve is horizontal. Walking in the \(+x\) direction from \(P\) therefore keeps us on the same level curve for a while, so \(f\) does not change to first order:
      \begin{equation*} \frac{\partial f}{\partial x}(P) \approx 0. \end{equation*}
      🔗
      🔗
    6. \(\dfrac{\partial f}{\partial y}\) measures how fast \(f\) changes as we move straight up, which is large where the contours are close together and small where they are far apart. At \(Q\) we only have to go up about \(0.25\) units to move from one contour to the next, so \(\dfrac{\partial f}{\partial y}(Q) \approx \dfrac{2}{0.25} = 8\text{.}\) At \(R\) we must go up about \(1\) unit for the same change, so \(\dfrac{\partial f}{\partial y}(R) \approx \dfrac{2}{1} = 2\text{.}\) Hence \(\dfrac{\partial f}{\partial y}(Q)\) is bigger.
      🔗
      🔗

    14.

    A sheet of metal of varying density occupies the \(xy\)-plane. At the point \((x,y)\text{,}\) the density is \(100 + 0.1xy + 0.1y^2\text{.}\) We move away from the point \((10,10)\) in the direction \(\frac35\mathbf i + \frac45\mathbf j\text{.}\) Use the directional derivative to estimate about how far we’ll have to go for the density to increase by \(6\text{.}\)
    🔗
    Solution.
    Let \(\rho(x,y) = 100 + 0.1xy + 0.1y^2\text{.}\) Then
    \begin{equation*} \nabla \rho = \langle 0.1y,\; 0.1x + 0.2y\rangle, \qquad \nabla \rho\big|_{(10,10)} = \langle 1,\; 1 + 2\rangle = \langle 1, 3\rangle. \end{equation*}
    The given direction is already a unit vector, since \(\left(\frac35\right)^2 + \left(\frac45\right)^2 = 1\text{,}\) so
    \begin{equation*} D_{\hat u}\rho(10,10) = \langle 1, 3\rangle \cdot \left\langle \frac35, \frac45\right\rangle = \frac35 + \frac{12}{5} = 3. \end{equation*}
    🔗
    So the density increases at about \(3\) units of density per unit of distance. To gain \(6\) units of density we therefore need to travel approximately
    \begin{equation*} s \approx \frac{6}{3} = 2 \text{ units}. \end{equation*}
